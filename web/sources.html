Two-bridge boundary slopes

The Hatcher–Thurston algorithm, adapted from Nathan Dunfield’s public-domain two-bridge program (1998; updated 2020). The original reference files and license declaration are included in the source archive. The browser adaptation uses exact integers, enumerates minimal Farey paths, and measures slopes relative to the Seifert longitude. Jim Hoste suggested this feature following his work with Pat Shanahan; their original CompuTop program is not used here.

Emscripten

The generated JavaScript runtime is produced by Emscripten 3.1.69. Emscripten's runtime is MIT licensed. The build needs Emscripten; running the app needs only a modern browser.

The source archive documents the portability changes. This is an independent browser port, not an official release from the original authors.
